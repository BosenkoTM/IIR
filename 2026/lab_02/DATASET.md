# Получение корпуса WikiQA

Ноутбуки пробуют загрузить данные по трём путям и останавливаются на первом успешном.
Достаточно обеспечить любой один из них.

## Путь 1 (рекомендуемый). Локальный файл

1. Скачайте архив `WikiQACorpus.zip` (≈ 7 МБ) с одного из источников:
   * Microsoft Download Center — https://www.microsoft.com/en-us/download/details.aspx?id=52419
   * зеркало на Kaggle — https://www.kaggle.com/datasets/saurabhshahane/wikiqa-corpus
2. Распакуйте архив.
3. Положите файл `WikiQA-test.tsv` в каталог `data/wikiqa/` рядом с ноутбуком:

```
lab_02/
├── lab_02_student.ipynb
└── data/
    └── wikiqa/
        └── WikiQA-test.tsv
```

Проверка: первая ячейка загрузки печатает `[OK] Источник данных: local (...)`.

## Путь 2а. Автоматическая загрузка через kagglehub

```bash
pip install kagglehub
```

Затем настройте доступ к Kaggle API: на странице https://www.kaggle.com/settings
создайте API-токен и положите `kaggle.json` в `~/.kaggle/` (Windows:
`C:\Users\<имя>\.kaggle\`). В Google Colab можно загрузить `kaggle.json` через
`files.upload()`.

Ноутбук вызовет `kagglehub.dataset_download("saurabhshahane/wikiqa-corpus")`
и сам найдёт нужный TSV-файл.

## Путь 2б. Hugging Face Hub

```bash
pip install datasets
```

Ноутбук вызовет `load_dataset("microsoft/wiki_qa", split="test")`. Схема колонок
там другая (`question_id`, `question`, `document_title`, `answer`, `label`) —
приведение к единому виду выполняется автоматически.

## Путь 3. Синтетическая заглушка (только отладка)

Если ни один из путей не сработал, генерируется синтетический набор той же
структуры и сопоставимой статистики. Он нужен исключительно для того, чтобы
можно было отладить код без интернета.

**Результаты на заглушке не засчитываются как выполнение лабораторной работы.**
Финальная самопроверка в студенческом шаблоне специально проверяет, что
`DATA_SOURCE != "synthetic"`.

## Контрольные значения (WikiQA-test.tsv)

| Показатель | Значение |
|---|---|
| Вопросов | 633 |
| Предложений-кандидатов | 6 165 |
| Предложений с `Label = 1` | 293 |
| Вопросов, у которых есть ответ | 243 |

Функция `describe_corpus()` печатает эти числа и сверяет их со справочными.

## Лицензия и репозиторий

Корпус распространяется по Microsoft Research Data License Agreement: преподавание
и академические исследования допустимы, но при распространении данных и производных
наборов нужно соблюдать исходные условия лицензии. Поэтому **файлы корпуса не
коммитятся в репозиторий** — в `.gitignore` уже добавлены `data/` и `*.tsv`.
В работе публикуется только код загрузки.
