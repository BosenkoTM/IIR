# Лабораторная работа № 1. Индексирование и булев информационный поиск

**Цель:** освоить подготовку текстов, построение инвертированного индекса и выполнение булевых запросов.

### Материалы

- Семинар: [Indexing](https://github.com/BosenkoTM/IIR/tree/main/seminars/03-indexing)
- Исходное задание: [HW1 — Boolean Retrieval](https://github.com/BosenkoTM/IIR/tree/main/homeworks/hw1-boolean-retrieval)

### Инструменты

Python 3.12, Jupyter Notebook, библиотеки из репозитория IIR.

## Ход работы

1. Клонируйте репозиторий IIR и запустите материалы семинара по индексированию.
2. Подготовьте корпус: токенизация, приведение регистра, удаление пустых токенов.
3. Реализуйте инвертированный индекс `term -> doc_id` и поиск по запросам `AND` и `OR`.
4. Выполните индивидуальный вариант из таблицы и измерьте время построения индекса и поиска.
5. Сформулируйте краткий вывод о влиянии размера корпуса и предобработки на поиск.

## Оформление и сдача

Работа размещается в GitHub-репозитории или отдельной ветке. Рекомендуемая структура:

```text
lab_01/
├── README.md
├── lab_01.ipynb
├── solution.py          # при необходимости
└── requirements.txt
```

В `README.md` указываются ФИО, группа, номер варианта, краткое описание метода, полученный результат и вывод. Код должен воспроизводиться после установки зависимостей из `requirements.txt`.
